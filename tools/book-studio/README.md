# 寻宝绘本工坊

配套入口 `/pbook/studio/`。静态网站负责相机、相册、排序、旋转、IndexedDB 草稿、状态轮询、校对和个人书架入口；此 Python 服务负责识字、逐句翻译、边界定位、逐句配音、时间轴和绘本打包。生成后沿用已有阅读器和独立熏听播放器。

## 当前上线边界

网页可拍照、整理并保存本机草稿。`pbook/studio/config.json` 的 `apiBase` 为空时，一键生成禁用，明确显示服务尚未接入。GitHub Pages 不执行此 Python 服务。需要另行提供 HTTPS 后台和可用的视觉/TTS 模型配置，才能实际生成；目前尚未使用真实模型完成验收。

每位用户的生成任务由本机随机身份隔离，发布只加入当前浏览器个人书架，不修改公共 catalog。新书会通过现有队列逻辑加入熏听列表。清除浏览器数据会丢失身份、草稿和书架入口；当前版本没有账号、跨设备恢复和公开分享管理。媒体地址包含高熵访问凭据，持有完整链接的人可以访问。

## 部署

1. 复制 `.env.example` 为 `.env`，在服务器填写视觉模型、语音模型接口和制作邀请码。密钥只存服务器，不放网页或 Git。视觉接口须支持图片输入及 JSON 输出，TTS 须兼容 `/audio/speech`、WAV 输出和 speed 参数。并非所有声称兼容的服务都支持这些能力。
2. 在此目录构建并运行（需要 Docker）：

```sh
docker build -t treasure-book-studio .
docker volume create treasure-book-data
docker run -d --name treasure-book-studio --restart unless-stopped \
  --env-file .env -p 127.0.0.1:8000:8000 \
  -v treasure-book-data:/data treasure-book-studio
```

3. 配置域名、TLS 及反向代理至本机 8000。上传大小上限至少 105 MB；上传超时 180 秒。可信反向代理必须覆盖客户端 IP 转发头，且只信任该代理，避免限额 IP 被伪造或所有用户共享一个代理 IP。
4. 将 `/health` 的 ready 检查为 true；设置 `pbook/studio/config.json` 为 `{"apiBase":"https://实际后台域名"}`，发布网页。
5. 先拍一本短书完成识别、试听、校对、加入书架、点读、熏听和倍速的真实验收，再开放公众使用。

默认单工作线程、每天每身份/IP 最多 3 次、最多 40 页/100 MB、最多 10 个排队任务。服务重启会将未完成任务标为失败，用户可重新提交本机草稿；暂不自动续跑，避免重复计费。正式对公众开放前应根据实际量设置模型侧预算上限、磁盘清理/备份和监控。数据目录必须持久化。

## 图像及语音行为

保留完整跨页，按模型给出的书本四边界显示，排除桌面背景；不使用拉伸填充或随意裁掉书中文字。文字模糊、被遮挡时提示对应页重拍。此版本**未接入此前人工批量使用的 AI 除物补画、调色服务**，不会声称自动恢复不可见的原文或原插画。

故事正文和对白逐句配音，封面及科普附页保留文字和译文但不配音。首次生成提供一个统一声音；语速调节沿用阅读器的 0.6/0.7/0.8/0.9/1.0/1.1/1.2/1.5/2.0。OCR、译文和坐标都可能需要校对。当前校对支持看图、逐句对照和试听；发现错误可返回整理照片后重新生成，尚无在线文字编辑器。

## 验证

```sh
python -m unittest discover -s tests -v
```

测试使用替代的识别和配音输入，验证真实音频拼接、生成格式及接口隔离；不等同于真实模型效果验收。浏览器相机还需在 iPad Safari 真机确认权限和拍摄体验。
